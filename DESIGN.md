# Draw & Guess UI

## Viewport layout

- Fit each screen’s primary content and controls within the visible viewport at typical device sizes, including landscape phones and short laptop windows.
- Use a viewport minimum height for the page shell. Adapt vertical padding and gaps to the available height while keeping controls and text comfortably sized.
- Let the page scroll naturally when content needs more room, such as with increased text size, a narrow viewport, or the on-screen keyboard. Keep keyboard-focused controls reachable.
- Check narrow phone, landscape phone, tablet, and short desktop viewports when implementing each screen. Include at least one check with increased text size.
